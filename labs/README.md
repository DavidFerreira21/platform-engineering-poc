# 🧪 Laboratórios

Os labs transformarão os contratos da plataforma em implementações **reproduzíveis, observáveis e seguras**. Esta pasta ainda é um marcador de estrutura: os laboratórios não foram implementados.

## Percurso recomendado

1. [📖 Fundamentos](../docs/fundamentos/README.md) — entender os conceitos antes das ferramentas.
2. [🏗️ Arquitetura](../docs/architecture.md) — compreender a divisão entre API, controllers e workflow.
3. [🛤️ Roteiro prático](../docs/learning-roadmap.md) — seguir as fases e evidências esperadas.

Cada lab deve cobrir preparação, passos verificáveis, observação de estados e eventos, falhas seguras, diagnóstico, recuperação, custos quando aplicável e limpeza. **AWS real somente com conta/região confirmadas e autorização explícita.**
