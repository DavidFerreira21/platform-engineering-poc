# 🏗️ UAT · Environment Management EKS

**Gerenciamento local do ambiente:** Argo CD, operators compatíveis e gateway de telemetria; acesso administrativo a workloads PCI deve ser avaliado.

| Atributo | Definição |
| :--- | :--- |
| Ambiente | **UAT** — conta AWS independente |
| Situação | **Planejado; não provisionado** |
| Tecnologia | Amazon EKS Auto Mode (padrão inicial) |
| Validação pendente | Operators, Argo CD, identidade e fronteira PCI |
